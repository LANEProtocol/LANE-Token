## LANE TOKEN (LANE)

### Overview

**LANE TOKEN (LANE)** is a multichain utility token within the LANE Protocol ecosystem. LANE is designed to support a decentralized ecosystem focused on services, payments, remittances, digital commerce, and other blockchain-based utilities across multiple networks. **Visit the general information page:** https://lanetoken.com/lane/

**LANE Protocol** provides the ecosystem and infrastructure within which the LANE token is utilized.

The LANE token is built as a multichain means of transfer, allowing its utility to extend across compatible blockchain networks. Its movement between networks is enabled through the LANE ecosystem's own bridge, built on **LayerZero V2** interoperability, allowing LANE to be transferred between compatible networks.

The community-driven nature of LANE allows **its holders and developers to create applications, services, and new utilities around LANE TOKEN**, expanding its potential use cases throughout the blockchain ecosystem.

**Visit LANE Bridge:**  
https://lanetoken.com/bridge/

## Core Utility

LANE is designed to support the following areas within the LANE Protocol ecosystem:

* **Staking:** https://lanetoken.com/staking/
* **Core Collateral:** used as collateral backing for **LANEX**, the ecosystem's stable token. https://lanetoken.com/collateral/
* **Payments**
* **Remittances**
* **Digital Commerce**
* **Multichain Interoperability**
